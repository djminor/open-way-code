# Bubble Sort: Comparator & Iterator
def bubble_sort(numbers):
    n = len(numbers)
    for i in range(n):
        for j in range(0, n - i - 1):
            # Compare adjacent items
            if numbers[j] > numbers[j + 1]:
                numbers[j], numbers[j + 1] = numbers[j + 1], numbers[j]
    return numbers

print(bubble_sort([5, 1, 4, 2, 8]))

The Origin

From a Community Workshop to an Open Platform

In 2026 I taught a free beginner coding class at United Way in Payson, UT. About halfway through the semester, I realized that something wasn't working, and my solution was OpenWay Code.

At the college level and in industry, it's natural and helpful to ensure that everyone in the class has their development environment set up perfectly so that everyone is on the same page and can most easily synthesize their work. But for young students just learning to code for the first time, especially students who might not have access to their own computer all the time, this can be a barrier to learning

OpenWay Code is meant to solve that problem by bridging the gap between an instructor who might have years of experience in the field and brand-new coding students who may or may not even have access to a computer outside of the classroom. It's free, and it always will be

For Teachers & Volunteers

Built to support educators in the room

OpenWay Code is meant to get rid of a lot of the decisions that volunteer educators often have to make when developing a new curriculum, namely what to teach and how to equip students to learn.

📽️
Classroom Projector Board
Press Alt+L inside the studio or open /instructor.html to project large-format, high-visibility step-by-step code for students to follow along and copy down live in class.
▶
Live Demonstration Engine
Run working reference code directly on the projector screen with adjustable classroom font sizing and 1-click injection into the student studio. This feature uses Skulpt to compile Python down into Javascript, so students don't need any additional installs to learn how to code.
⏱️
60-Minute Lesson Pacing
Each module follows a structured 4-stage cadence: 15m Concept Hook → 20m Guided Walkthrough → 15m Student Mission → 10m Student Demos.
